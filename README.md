# Ishan Trivedi — Portfolio

A single-file static portfolio published to GitHub Pages. It has no client-side framework, chatbot, API route, environment variables, or server deployment.

## Deploy

Pushing to `main` runs the GitHub Pages workflow. The workflow installs no packages and copies `index.html` plus `public/` into the published `dist/` folder.

## Check locally

```bash
npm ci
npm run lint
npm run build
```
